# 03 · 菜单配置

> 配置位置：`config/ccnr_menu/menu.json`（首次启动自动生成）。
> 同目录下另有一份 `menu.example.json`（带全套示例的参考文件，**不参与加载**，随便改）。
> 背景素材也放在 `config/ccnr_menu/`（子目录可以，**不允许 `../` 越界**）。

改完不必重启：回到主菜单看一眼（打开时会比较文件修改时间），或执行 `/ccnr_menu reload`。
任何字段写错都会在 `/ccnr_menu status` 与日志里给出**带原因**的警告。

---

## 1. 顶层字段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | `false` = 完全不接管主菜单（第一条退路） |
| `vanillaButtons` | bool | `false` | `true` = 用原版那套按钮（单人/多人/设置/退出/Mods），此时只看背景与配色 |
| `applyToAllScreens` | bool | `true` | 是否把这份背景也铺到**原版泥土背景的界面**（世界选择/多人列表/设置/语言/Mod 列表）。世界内的界面（暂停、背包）**永远不动** |
| `background` | object | `{"type":"slideshow",…}` | 见 §2 |
| `mark` | object | — | 泥土页面上的标志（默认在右下角），见 §2.2（不写就是不画） |
| `theme` | object | 见 §3 | 配色与按钮外观 |
| `elements` | array | `[]` | 见 §4；`vanillaButtons=false` 时**至少要有一个 button**（否则自动退回原版按钮） |

## 2. `background`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type` | string | `vanilla` | `vanilla` / `slideshow` / `image` / `sheet` / `gif` / `color` / `none` |
| `file` | string | — | 素材路径（相对 `config/ccnr_menu/`）；`vanilla`/`slideshow`/`color`/`none` 不需要 |
| `fit` | string | `cover` | `cover`（铺满裁切）/ `contain`（完整可见留边）/ `stretch`（拉伸）/ `center`（原尺寸）/ `tile`（平铺） |
| `tint` | color | `#FFFFFF` | 与原图相乘的着色（`#808080` = 压暗一半） |
| `opacity` | number | `1.0` | 0~1 |
| `color` | color | `#101014` | 仅 `type=color`：底色 |
| `animation` | object | — | 见下（`sheet` / `gif` 用） |
| `slides` / `holdMs` / `fadeMs` / `zoom` / `panX` / `panY` / `loop` | — | — | 仅 `type=slideshow`，见 §2.1 |

`animation` 子字段：

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `cols` / `rows` | int | `1` | 精灵图网格（仅 `sheet`） |
| `frames` | int | `0` | 实际帧数；`0` = 用满 `cols*rows`（仅 `sheet`） |
| `fps` | number | — | 每秒帧数（与 `frameMs` 二选一，仅 `sheet`） |
| `frameMs` | int | `100` | 每帧毫秒（仅 `sheet`） |
| `loop` | bool | `true` | 是否循环 |
| `speed` | number | `1.0` | 播放倍速（`2` = 快一倍） |

> `gif` 的**帧时长由 GIF 自带的 `delayTime` 决定**，`fps`/`frameMs` 对它无效；
> `loop` 与 `speed` 对两者都有效。

### 2.1 `slideshow`：多图轮播

几张图轮着放，切换时淡入淡出，每张再放大一点点并缓慢往右偏移。原理与取舍见 docs/02 §1.1。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `slides` | string[] | — | 图片列表（相对 `config/ccnr_menu/`），数组顺序就是播放顺序 |
| `holdMs` | int | `9000` | 每张显示多久（400 ~ 300000） |
| `fadeMs` | int | `1400` | 末尾交叉淡入的时长；比 `holdMs` 长时会被收窄到 `holdMs` 并警告 |
| `zoom` | number | `0.08` | 每张图在显示期间放大的比例（`0.08` = 放大到 1.08 倍；0 = 不放大） |
| `panX` | number | `0.05` | 每张图向右偏移的比例（相对**屏幕宽度**；负数向左） |
| `panY` | number | `0.0` | 每张图向下偏移的比例（相对屏幕高度；负数向上） |
| `loop` | bool | `true` | `false` = 播完停在最后一张 |

```json
"background": {
  "type": "slideshow",
  "fit": "cover",
  "tint": "#A6A6A6",
  "holdMs": 9000,
  "fadeMs": 1400,
  "zoom": 0.08,
  "panX": 0.05,
  "slides": ["slides/01.jpg", "slides/02.jpg"]
}
```

> 运镜是**每张图各自从头走一遍**（而不是整条时间轴连续走）：连续走的话，切到第 5 张时
> 画面已经放大到 1.4 倍了，那张图一出现就是糊的。
> `slides` 是空的（或根本没写）会警告——那会在屏幕上只剩一块纯色，而作者以为轮播配好了。

### 2.2 `mark`：泥土页面上的标志（默认右下角水印）

那些页面没有自己的元素布局，不加这个就只剩一张背景图。原理见 docs/02 §1.2。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `file` | string | — | 图片文件（相对 `config/ccnr_menu/`）。空字符串会警告并当成不画 |
| `width` | int | 原图宽度 | 显示宽度（1~4096）；高度按原图比例算 |
| `opacity` | number | `1.0` | 0~1 |
| `x` / `y` | number | `0.5` | 分数锚点（0~1），默认正中 |
| `align` | `center` | `x` 指的是标志的**哪一条边**：`left` / `center` / `right` |
| `valign` | `middle` | `y` 指的是哪一条边：`top` / `middle` / `bottom` |
| `onMainMenu` | bool | `false` | 是否也画在主菜单上——主菜单左列里已经有图标了，默认不画 |

```json
"mark": { "file": "logo_wide_mono.png", "width": 420, "opacity": 1.0,
          "x": 0.98, "y": 0.95, "align": "right", "valign": "bottom" }
```

> `align`/`valign` 的意义：`x: 0.98, align: right` = **标志的右边缘**落在屏幕 98% 处，
> 于是右边距是 2%——这就是「右下角、不贴边」的写法。默认（`center`/`middle`）与老配置完全一致。
> 想回正中间：`"x": 0.5, "y": 0.5, "align": "center", "valign": "middle"`。

> 标志画在**原版控件之前**，所以设置页面上它会落在选项列表下面——水印不该盖住按钮。

## 3. `theme`

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `buttonStyle` | `solid` | `solid` = 有底色+描边+左侧强调竖条；`text` = **无背景纯文字**（见下） |
| `backdrop` | `#66000000` | 背景之上、文字之下的压暗层。**它是可读性保障**：高亮背景会让白字看不清；不想要可设 `#00000000`（默认配置就是，因为底色本来就是纯黑） |
| `buttonFill` | `#B0121216` | 按钮底色（仅 `solid`） |
| `buttonFillHover` | `#D01E1E26` | 悬停底色（仅 `solid`） |
| `buttonBorder` | `#FF3C3C46` | 按钮描边（仅 `solid`） |
| `buttonBorderHover` | `#FF4FD1E0` | 悬停描边（仅 `solid`） |
| `buttonText` | `#FFE6E6EE` | 按钮文字 |
| `buttonTextHover` | `#FF4FD1E0` | 悬停文字 |
| `accent` | `#FF4FD1E0` | 强调色（`solid` 的左侧竖条、`text` 的焦点下划线） |
| `labelText` | `#FFCFCFD8` | 文字元素颜色 |

颜色写法：`#RGB` / `#RRGGBB` / `#AARRGGBB`（`#` 与 `0x` 都可省略前缀）。
写错时用默认色并给出警告——不会静默变成白色。

### 3.1 `buttonStyle: "text"`：无背景纯文字

不画底色、描边、强调竖条，标签从按钮矩形**左边缘**起画（`solid` 是居中）。
两点行为值得先知道：

- **不写 `width` 时按钮宽度贴着文字**。纯文字按钮的热区是看不见的，
  若还留 200 宽的隐形矩形，鼠标停在文字右边两厘米的空白上文字也会变色——看起来像按钮坏了。
  写了 `width` 就按写的来（那是明确的要求）。
- **键盘焦点用文字下划线表达**。`solid` 用「内描边 = 焦点、外描边色 = 悬停」；
  纯文字没有描边可用，于是改成「下划线 = 焦点、变色 = 悬停」。
  「焦点与悬停必须是两个视觉通道」这条纪律不因为换了外观就丢掉——
  共用通道的症状是 Tab 选中后鼠标再移上去，就看不出到底选中了哪一个。

## 4. `elements`

数组元素共三种 `type`，共用同一套摆放字段。

### 4.1 通用字段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type` | string | `button` | `button` / `label` / `image` |
| `x` / `y` | number | `0.5` | **0~1 的分数锚点**（相对于屏幕宽高） |
| `align` | string | `center` | `x` 落在元素的哪条竖边上：`left` / `center` / `right` |
| `valign` | string | `middle` | `y` 落在元素的哪条横边上：`top` / `middle` / `bottom` |
| `offsetX` / `offsetY` | int | `0` | 摆好之后的**像素**微调（做 2px 细缝这类事） |
| `width` / `height` | int | 自动 | 像素尺寸；不写则按类型取默认（`solid` 按钮 200×20；`text` 按钮贴着文字；图片用原始尺寸） |
| `color` | color | 主题色 | 文字/标签颜色覆盖 |
| `shadow` | bool | `true` | 文字阴影 |

### 4.2 `button`

| 字段 | 说明 |
| --- | --- |
| `text` | 按钮文字。以 `ccnr_menu.` 开头按**语言键**翻译，否则按字面量显示 |
| `action` | 动作（见 §5） |
| `value` | 动作参数（也可以直接写在 `action` 里用 `:` 分隔） |

### 4.3 `label`：只有文字，`scale` 控制缩放倍数（0.25~8）

### 4.4 `image`：`file` 指向 `config/ccnr_menu/` 里的图片

- 只写 `width` 或 `height` 时按原图比例补另一个（不会拉伸变形）；
- 带 `animation` 时变成**序列帧动画**，参数与背景的 `animation` 完全一样
  （`cols`/`rows`/`frames`/`fps`/`frameMs`/`loop`/`speed`）：

```json
{ "type": "image", "file": "logo_wide_intro_mono.png", "width": 360,
  "animation": { "cols": 8, "rows": 10, "frameMs": 33, "loop": false } }
```

  `loop: false` 表示**入场动画播一次就停在末帧**（图标设计的原意：intro, one-shot then still）。
  比例按**单帧**算，不是按整张精灵图算——只写 `width` 就够了。
  内置图标是 8 列 10 行 = 80 帧 / 每帧 33ms ≈ 30fps，**网格要与素材实际一致**，
  写错了动画会错位（`PresetAssetsTest` 会把配置与生成脚本的规格钉在一起）。

### 4.5 `column`：竖列容器

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `children` | — | 子元素（自上而下；类型与顶层元素完全相同，可以再嵌套容器，最多 4 层） |
| `gap` | `8` | 相邻子元素间距（像素） |
| `childAlign` | `center` | 子元素**在列宽之内**的横向对齐：`left` / `center` / `right` |
| `width` | 最宽的子元素 | 列宽（像素）。**建议给定**：这样按钮不会因为图标更宽而左右跳 |
| `bar` | — | 列背后的**满屏高色带**，见下（不写就不画） |

#### 列背后的色带 `bar`

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `color` | `#33000000` | 颜色（含 alpha）。`#33000000` = 20% 黑 |
| `width` | `buttons` | `buttons` = 按钮们**实际占据的范围**；`column` = 整列宽（和图标同宽） |

色带高度是**满屏高**，画在**所有子元素之前**，所以图标与按钮都在它之上（不会盖住图标）。
它跟着列走是因为位置与宽度都得由这一列决定：按钮宽度是随文案变的（`text` 外观下贴着文字），
写成固定像素或整列宽都会和按钮错开。

容器自己按通用字段摆放（`x`/`y`/`align`/`valign`）；子元素的 `x`/`y` 在容器里**不起作用**
（位置由容器决定），但 `offsetX`/`offsetY` 仍然生效。

**「整块靠左、图标与按钮列左对齐」就是这么配的**（当前默认）：

```json
{ "type": "column", "x": 0.10, "y": 0.5, "align": "left", "valign": "middle",
  "width": 300, "gap": 10, "childAlign": "left",
  "bar": { "color": "#33000000", "width": "buttons" },
  "children": [
    { "type": "image", "file": "logo_wide_intro_mono.png", "width": 300, "animation": { "cols": 8, "rows": 10, "frameMs": 33, "loop": false } },
    { "type": "button", "text": "进入服务器", "action": "screen:multiplayer" },
    { "type": "button", "text": "单人游戏", "action": "screen:singleplayer" },
    { "type": "button", "text": "设置", "action": "screen:options" },
    { "type": "button", "text": "退出游戏", "action": "quit" }
  ] }
```

- `align: left` → 整块贴左（`x` 是左边缘的分数位置）；
- `childAlign: left` → 列内子元素左边缘对齐 → 图标左边缘 = 按钮左边缘；
- 按钮没写 `width`：`theme.buttonStyle` 是 `text` 时宽度贴着文字（见 §3.1）；
- 想更靠边或更靠中间：改 `x`（`0.10` 是当前默认，越大越靠中间）；
- 想改成**靠右**：`"x": 0.955, "align": "right", "childAlign": "right"`；
  想**居中**：`"x": 0.5, "align": "center"`。

> **尺寸怎么选**（默认值就是这么定的）：元素用的是**绝对像素**，而 GUI 尺寸随窗口与缩放变化——
> 常见的最小值是 320×240 个 GUI 单位（小窗口），1080p 缩放 2 是 427×240。
> 默认的 `300 宽 / 列高约 212` 在上述所有尺寸下都放得下；如果你把图标调大导致超出屏幕，
> 模组会在日志里**明确列出哪个元素超了多少**（不是无声地裁掉一块），
> 这时要么减小 `width`，要么让玩家把 GUI 缩放调小。

## 5. 动作（`action`）

| 写法 | 作用 |
| --- | --- |
| `screen:<id>` 或 `vanilla:<id>` | 打开原版界面。`<id>` ∈ `singleplayer` / `multiplayer` / `options` / `language` / `accessibility` / `mods` / `credits` |
| `connect:<地址>` | 直连服务器。地址形如 `play.example.com` 或 `play.example.com:25565` |
| `url:<链接>` | 用系统默认浏览器打开。**只接受 `http://` 与 `https://`** |
| `copy:<文本>` | 复制到剪贴板（适合让玩家复制群号/IP） |
| `quit` | 退出游戏 |
| `none` | 什么都不做（写出来的占位，便于先摆好位置再填动作） |

> **为什么 `url` 只允许 http/https**：配置可以被转发（服主发一份「好看的菜单」给玩家），
> 而 `url` 最终交给操作系统的默认程序打开。`file:` 会让客户端去打开本机文件，
> 所以任何非 http(s) 协议一律拒绝——不试图枚举危险协议，枚举法总会漏。

      "x": 0.5, "y": 0.58, "width": 200 },

## 7. 内置素材（随模组发布，首次运行自动释放）

`config/ccnr_menu/` 里会出现这些文件（**已存在则不覆盖**，可以随意替换）：

| 文件 | 用途 |
| --- | --- |
| `background.png` | 背景图（1920×1080） |
| `logo_wide_intro_mono.png` | 横版图标**入场动画**精灵图（**全白单色**；8×10 = 80 帧 ≈30fps） |
| `logo_wide_mono.png` | 同一图标的静态末帧（全白单色） |
| `logo_wide_intro_white.png` / `logo_wide_white.png` | 彩色版本（浅色图形 + 品牌青，配深背景） |
| `slides/01.jpg` … `slides/11.jpg` | 轮播照片（已压到 1920 宽、JPEG 质量 82，合计 2.7MB） |

默认配置用的是**全白图标 + 轮播照片背景**：照片本身颜色就多，
图标再带自己的强调色就会互相抢戏。想要彩色图标就把文件名换成 `*_white.png`。

换轮播照片：把新图放进 `config/ccnr_menu/`（子目录随意），改 `background.slides` 即可。
要**重做内置的那 11 张**：把源图放进 `~/Downloads/`，在脚本的 `SLIDE_SOURCES` 里按想要的顺序
列出来（清单即编号即轮播顺序，缺一张脚本会报错退出），再执行
`python3 scripts/make-icon-presets.py --only-slides`，重新构建并提交产物。
不要改成扫目录的 glob：`~/Downloads` 里躺着无关图片时会被一起卷进来。

素材由 `scripts/make-icon-presets.py` 从 CCNR 图标的 SVG **预渲染**而来（需要 Chrome + python3），
**不要手改 resources 里的文件**——改了生成脚本就要重跑并提交产物，
`PresetAssetsTest` 会把「配置引用」「素材清单」「磁盘文件」三者对齐。

## 8. 只换背景、不动按钮

```json
{
  "enabled": true,
  "vanillaButtons": true,
  "background": {
    "type": "slideshow",
    "slides": ["slides/01.jpg", "slides/02.jpg", "slides/03.jpg"],
    "holdMs": 8000,
    "fadeMs": 1500
  }
}
```

## 9. 排查

| 现象 | 先看什么 |
| --- | --- |
| 主菜单和原版一样 | `/ccnr_menu status` 的「生效」与「背景」两行；`enabled=false` 或 `type=vanilla` 都会这样 |
| 按钮点了没反应 | 该按钮是否出现在 `status` 的列表里（不在 = 动作不合法被跳过，警告里有原因） |
| 背景没换 | `status` 的「背景」行会显示 `[文件不存在]` 或 `[路径越界]` |
| 轮播只有一张 / 一直停在第 0 张 | `status` 会逐张列出 `[文件不存在]`；`holdMs` 是不是被配得极大 |
| 轮播切图时卡一下 | 那张图的解码没赶上（正常应在上一个周期就解好）；看日志有没有「轮播素材加载失败」 |
| 泥土页面上没有白色图标 | 没写 `mark`，或 `mark.file` 不在配置目录 |
| 换了内置素材但游戏里还是旧的 | 0.5.0 之前的老版本：`config/ccnr_menu/` 里同名旧文件不会被覆盖，手动删掉它或升级到 0.5.0+（0.5.0 起按内容比较，会自动更新并留 `.bak`） |
| 按钮文字亮起来的位置不对 | `buttonStyle: text` 下不写 `width` 才会贴着文字（§3.1） |
| 配置里还写着 `type: "text"` | 该类型已在 0.4.0 移除 → 会退回原版全景图并给出警告；改用 `slideshow` 或 `image` |
| 文字看不清 | `theme.backdrop` 调大（压暗层更深） |
| 想确认用的是哪份配置 | `/ccnr_menu where` 给出配置目录的绝对路径 |
| 升级后菜单没变 | 自己改过 `menu.json` 时升级**不会**动它（这是有意的）；想要新版默认执行 `/ccnr_menu reset`（会先把原文件备份成 `.bak`） |
